# 最多两个候选（未实施）

## A：通用Prompt v3证据范围约束

陈述范围不得超过自身refs能支持的范围。全称/批量/排他/整个历史缺失命题须充分覆盖或引用已有权威范围汇总；否则收窄为已引证的个案/局部证据界限。
不编造汇总/来源，不机械加30refs，不用其他facts隐式补证；保留原精确身份/里程碑/依赖/条件。只改版本化指令，不改Schema/输入/切点。
不增加调用，只少量Prompt Tokens；请求前重新预算。Snapshot和持久化恢复语义不变。
能针对本次6条范围引证缺口；不保证通用语义完整性。风险：过度收窄或删除关键事实、引用膨胀挤占Snapshot预算。
最小验证见实验提案，未增加Judge/换模型/扩大预算。

## B：Eval-only确定性提示检查

仅对已识别的显式数字范围及独立工作项标签，核验覆盖；若有权威汇总或无法抽取则交人工，不按refs数量直接失败。可标记显式prefix否定需要人工复核。
能发现本次1—30只引用1/30的明显模式；难以识别“上述”指代、任意否定/比例/语义蕴含，不能做通用语义验证器。
仅离线Eval，零模型成本、无Schema/Runtime/恢复改动。风险：合法汇总误报、同义表述漏报、正则被误当证明；禁止删除或改写Snapshot事实自救。
优先架构简单：先统一人工规则与离线对抗夹具，再决定是否值得加提示检查，不直接接入Production强拒绝。
