# 人工边界与资格检查

检查器不解析自然语言。每个case的claim_model、source claims、对象集合、可信范围、effective_at由人工核对并预注册；自动测试只验证其后的集合蕴含和三维分类。
历史六条原文/refs/切点/response_id完整保留，来源正文见original_message和原audit_entry。本次没有据运行结果改历史判定。
必须人工确认：上述/这些/相关/主要的指代和范围，来源是否权威及汇总是否完整，是否显式状态更新，否定的搜索范围是否穷尽，复合句分解和新语义。
多数例只在人工确定主要=固定集合过半后使用16/30阈值；不能把这个解释推广到任意中文“主要”。
时间更新例只有明示更正才按有效时间顺序，冲突未解决用UNCERTAIN；不能泛化为后收到文本就一定覆盖真实事实。
“没有测试执行证据”历史规范化是原prefix全部消息的人工资格确认，不是正则根据缺少关键词判不存在。
自动可靠范围：已规范化的明确身份、截止位置、显式范围与原子属性覆盖、明确资料排他性、必要子命题组合。
历史正对照包含10/30项全覆盖、单项阅读、完整调用+结果以及原文唯一性；未机械按refs数量或命中全称词判失败。
未识别的NL不应默认PASS，也不能强行FAIL；应输出人工复核状态。该机制不得接入Production拒绝逻辑或宣传通用语义验证器。
