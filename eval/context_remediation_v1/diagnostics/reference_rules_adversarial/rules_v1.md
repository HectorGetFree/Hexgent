# Reference Sufficiency Scoring Contract v1

A来源合法、B完整前缀支持、C自身refs充分分别判断；不合并其他Fact refs。复合子命题逐一判断，必要一项不足则整条不PASS。
全称/范围/多数/否定/排他需范围、属性、时间均有证据；权威汇总或一条完整工件可覆盖多个对象，不能按refs个数机械拒绝。
不自动信任汇总标题，汇总内容/范围/可信性由人工资格确认；模糊指代/范围、同一有效时间冲突交UNCERTAIN，不默认PASS或FAIL。
声明不存在必须有负向证据或完整范围检查，信息未提供不是不存在；FAIL表示不能支持，不表示证明事实为假。
明确后续状态更新使旧状态不再有效；无法可靠解释更新时交人工，而不是泛化latest-wins。确定性模型的effective_at/显式更新先由人工确认。
支持若干子命题不能掩盖其他子命题缺证据。合理收窄可以引用充分，但仍单独检查Oracle身份/里程碑/关键依赖是否保留。
OVERGENERALIZATION可重叠REFERENCE_GAP，按唯一case/fact计问题，不重复累计；多个其他标签也保留。UNCERTAIN单独统计，不视作已确定错误。
checker只对已经人工规范化的原子命题/对象集合/来源有效性做确定性集合覆盖，不读取预期结果，不解析自然语言或证明人工注释正确。
合格需两层：来源/语义人工资格确认＋模型覆盖检查；禁止把结构测试全绿宣传为自然语言泛化正确率。
测试答案expected_results独立保存，manifest先冻结；不能运行后改答案。
